# Qadam SAT

Daily, bite-sized practice for the digital SAT Reading & Writing section: a skill path through all four domains, streaks, XP, hearts, vocabulary flashcards, a mistakes review, personal stats, and a live class dashboard for the teacher.

- Live site: https://said26998.github.io/qadam-sat/
- Setup (Firebase + GitHub Pages): [SETUP.md](SETUP.md)
- Edit questions in `source/content.js` or the app in `source/app.html`, then run `python3 source/build.py` to regenerate `index.html`.
